# speedtest

Консольный скрипт на Node.js, который замеряет скорость скачивания: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и считает среднее время запроса, общий объём данных и скорость.

## Требования

Node.js 18 или новее (используется встроенный `fetch`). Зависимостей нет, `npm install` не нужен.

## Запуск

```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
node speedtest.js <url>
```

В качестве адреса подойдёт любой тяжёлый файл, например:

```bash
node speedtest.js "https://speed.cloudflare.com/__down?bytes=5000000"
```

Если в адресе есть `?` или `&`, возьмите его в кавычки, иначе оболочка разберёт эти символы по-своему.

## Пример вывода

```
Адрес: https://speed.cloudflare.com/__down?bytes=5000000
Запросов: 10

  # 1     859 мс  5.00 МБ
  # 2     882 мс  5.00 МБ
  ...
  #10     442 мс  5.00 МБ

Среднее время запроса: 375 мс
Скачано всего:         50.00 МБ (50000000 байт)
Скорость скачивания:   106.73 Мбит/с (13.34 МБ/с)
```

## Единицы измерения

| Величина | Единица |
| --- | --- |
| Скорость скачивания | **Мбит/с** — мегабиты в секунду, как в тарифах провайдеров. В скобках то же значение в МБ/с |
| Объём данных | МБ (мегабайты) и точное число байт |
| Время запроса | мс (миллисекунды) |

Приставки десятичные: 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит, 1 байт = 8 бит.

## Как считается

- **Время запроса** — от отправки запроса до получения последнего байта тела. В него входят установка соединения и ожидание первого байта, а не только передача данных.
- **Среднее время запроса** — сумма времён всех запросов, делённая на 10.
- **Общий объём** — сумма размеров тел всех 10 ответов. Заголовки не учитываются.
- **Скорость** — общий объём, делённый на суммарное время всех запросов.

Запрос отправляется с заголовком `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и размер тела совпадал с тем, что реально передано по сети.

## Ошибки

Скрипт завершается с кодом 1 и сообщением, если адрес не передан или некорректен, сервер ответил не 2xx, либо сеть недоступна.
