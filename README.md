# speedtest

Консольный скрипт на Node.js, который замеряет скорость скачивания. Он делает 10 запросов к указанному адресу строго по очереди, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость в **Мбит/с**.

Зависимостей нет — только стандартная библиотека Node.js.

[![tests](https://github.com/Nursik72reg/-console-script/actions/workflows/test.yml/badge.svg)](https://github.com/Nursik72reg/-console-script/actions/workflows/test.yml)

## Соответствие заданию

| Требование | Где реализовано |
| --- | --- |
| Принимает адрес | первый аргумент командной строки, проверка — `readOptions` в `speedtest.js` |
| 10 запросов последовательно | цикл с `await` — `runSeries` в `src/measure.js` |
| Дожидается полного ответа | тело читается до последнего байта — `download` в `src/measure.js` |
| Среднее время и общий объём | `summarize` в `src/stats.js` |
| Скорость скачивания в консоль | Мбит/с — `printSummary` в `speedtest.js` |

## Запуск

Нужен Node.js 20 или новее. `npm install` не требуется.

```bash
git clone https://github.com/Nursik72reg/-console-script.git
cd ./-console-script
node speedtest.js <url>
```

В качестве адреса подойдёт любой тяжёлый файл, например:

```bash
node speedtest.js "https://speed.cloudflare.com/__down?bytes=5000000"
```

Если в адресе есть `?` или `&`, возьмите его в кавычки — иначе оболочка разберёт эти символы по-своему.

### Опции

| Опция | Что делает | По умолчанию |
| --- | --- | --- |
| `-n`, `--count <число>` | сколько запросов сделать | 10 |
| `-t`, `--timeout <секунды>` | таймаут одного запроса, не больше 86 400 | 30 |
| `--json` | вывести результат в JSON, без таблицы | выключено |
| `-h`, `--help` | показать справку | |

## Единицы измерения

| Величина | Единица |
| --- | --- |
| Скорость скачивания | **Мбит/с** — мегабиты в секунду, как в тарифах провайдеров. В скобках то же значение в МБ/с |
| Объём данных | МБ (мегабайты) и точное число байт |
| Время | мс (миллисекунды) |

Приставки десятичные: 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит, 1 байт = 8 бит. Поэтому 1 МБ/с = 8 Мбит/с.

В режиме `--json` числа не округляются: время в миллисекундах (`...Ms`), объём в байтах (`totalBytes`, `bytes`), скорость в Мбит/с (`mbps`).

## Как считается

- **Время запроса** — от отправки запроса до последнего байта тела ответа. В него входят установка соединения и ожидание ответа сервера, а не только передача данных.
- **Среднее время запроса** — сумма времён всех запросов, делённая на их количество. Рядом печатаются медиана, минимум и максимум: по ним видно, насколько замеры разбросаны.
- **Ожидание ответа сервера** — среднее время от отправки запроса до получения заголовков ответа.
- **Общий объём** — сумма размеров тел всех ответов. Заголовки не учитываются.
- **Скорость скачивания** — общий объём, делённый на суммарное время всех запросов. Это не среднее скоростей отдельных запросов: иначе один короткий удачный запрос завышал бы итог.

## Что влияет на результат

- **Размер файла.** На маленьком файле почти всё время уходит на соединение и ожидание сервера, и скорость получается заниженной. Берите файл от нескольких мегабайт.
- **Первый запрос медленнее остальных.** На него приходятся DNS, TCP и TLS; следующие запросы переиспользуют уже открытое соединение. Это видно в примере выше.
- **Сервер.** Скрипт меряет скорость до конкретного сервера. Если тот сам отдаёт медленно, результат покажет его предел, а не предел вашего канала.
- **Сжатие.** Запрос уходит с заголовком `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и размер тела совпадал с переданным по сети.
- **Кэш.** Запрос уходит с `cache: 'no-store'`, ответ каждый раз скачивается заново.

## Ошибки

Скрипт пишет причину в stderr и завершается с кодом 1, если:

- адрес не передан, некорректен или не `http(s)`;
- опция неизвестна или её значение некорректно;
- сервер ответил не 2xx;
- запрос не уложился в таймаут или сеть недоступна;
- сервер вернул пустые ответы.

Серия прерывается на первой же ошибке: неполный замер не выдаётся за результат.

## Устройство

```
speedtest.js             точка входа: аргументы, вывод, коды выхода
src/measure.js           сеть: один запрос и серия запросов по очереди
src/stats.js             арифметика: объём, среднее, медиана, скорость
test/stats.test.js       тесты арифметики
test/speedtest.test.js   тесты сети и CLI на локальном HTTP-сервере
```

Тело ответа читается потоком и сразу отбрасывается — считается только размер, поэтому файл любого объёма не занимает память.

## Тесты

```bash
npm test
```

Интернет для тестов не нужен: они поднимают HTTP-сервер на `localhost`. Проверяется, в частности, что запросов ровно 10 и что они не идут параллельно. На GitHub тесты запускаются автоматически на Node.js 20, 22 и 24.
